Main changes (see ai_fixes_to_review.md for the full list)
-----------------------------------------------------------
Blocking outside types
- type_helper.rb: ParentsHelper.init_list snapshots RDL; subtract() moves every pre-existing RDL entry
  (schema, ActiveRecord typedefs, stdlib) into ParentsHelper.blocked.

Inference
- infer_types.rb: newsuccess/newerror flags reset correctly; learned class methods registered as self.m;
  declared DynamicType read/write effects carried onto learned signatures.
- track_rewrite.rb: nested moi calls are now instrumented (processed children were discarded, misaligning the
  tracelist and recording wrong types).
- instrumented_assertions.rb (new): inference runs also observe moi calls inside the spec's assertions
  (guarded; falls back to the original assert when instrumenting could change meaning).
- type_ops.rb: class receivers also search [s]DynamicType (class-method placeholders such as self.exists?);
  methods_of copies cheaply instead of Marshal deep copies.
- dyn_arg_exhaustion.rb (new): %dyn argument holes are concretized to learned signatures once their
  (receiver, method, position, depth) is exhausted (watermark = smallest program size in the work list).
- learned_type_writeback.rb (new): learned types are written back into hole-free candidates on re-scoring.

Search
- syn_helper.rb: separate orderings for inference on (errors, size, passed asserts) and off (errors, passed
  asserts, size); passed_asserts sign fix; precedence fix in the correct-program check; deduplication of
  finished programs by source and of the work list by a structure key (ProgWrapper#structure_hash);
  generate(switch_after:) and generate_typed_then_inference; optional SWEEP_DYN=1 single-pass mode
  (experimental, not developed further).
- prog_wrapper.rb: prog_size cached; %dyn exempt from the variance filter; structure key; write-back.
- check_error_pass.rb: a begin around a call counts as %dyn only if the call is still unknown.
- refine_types_v2.rb (new): RefineTypesPass + DynamicRefineTypes in one pass; callers switched.
- extract_ast_pass.rb: shallow environment copy per combination (was a full deep copy; 12 MB for hash-key
  variants). Verified identical on 7,200+ combinations; EXTRACT_DEEP_COPY=1 restores the old copy.

Synthesizer
- spec_type_guard.rb (new) + synthesizer.rb: specs after the first run typed-only unless their argument or
  assertion types are new; typed-only searches fall back to an inference pass if they run out of candidates.
  INFERENCE_EVERY_PASS=1 restores inference before every search.
- prog_tuple.rb: merge-step condition searches are typed first, switching to an inference pass after the
  inference budget of iterations without a solution.

Benchmark spec
- test/benchmark/diaspora/user_confirm_email_benchmark.rb: %dyn getter declarations for email and
  confirm_email_token, both added to moi.
